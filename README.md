# Route Planner SPA

## Kurulum

```bash
npm install
npm run dev
```

## Router notu

Bu proje **react-router-dom v6** kullanır ve bağımlılık `package.json` içinde tanımlıdır.

Eğer ortamınızda `react-router-dom bu yok hiç` hatası alırsanız:

```bash
npm install react-router-dom@^6
npm run deps:check
```

> Bu repo içinde route tanımları `src/app/router.tsx` dosyasındadır.
